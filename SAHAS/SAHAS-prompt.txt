Common Signal Processing Techniques for Industrial Data Cleaning
Given the expected issues, here’s a structured approach:

Noise Reduction – Use low-pass filters, moving average smoothing, or wavelet denoising to remove high-frequency noise.

Handling Missing/Intermittent Data – Apply interpolation (linear, spline, or nearest neighbor) to reconstruct missing values.

Drift & Bias Correction – Detect slow trends using detrending, exponential moving averages, or adaptive filtering.

Outlier Removal – Use statistical methods (Z-score, IQR filtering) or machine learning-based anomaly detection.

String-Based Sensor Failures – Convert failure codes to NaN or categorical markers for downstream analysis.

Resampling to a Consistent Sampling Rate – Utilize time-series resampling and synchronization techniques.

import pandas as pd
import numpy as np
import scipy.signal as signal
from scipy.interpolate import interp1d
from sklearn.preprocessing import RobustScaler

# Load raw CSV data
file_path = "data/industrial_sensor_data.csv"
df = pd.read_csv(file_path)

# Convert timestamps
df["timestamp"] = pd.to_datetime(df["timestamp"])
df.set_index("timestamp", inplace=True)

# 1. **Noise Reduction** - Apply a moving average filter
window_size = 5  # Adjust for smoothing strength
df["filtered_signal"] = df["raw_signal"].rolling(window=window_size, center=True).mean()

# 2. **Intermittent Data Handling** - Linear interpolation for missing values
df["interpolated_signal"] = df["filtered_signal"].interpolate(method="linear")

# 3. **Drift & Bias Correction** - Detrending
df["detrended_signal"] = signal.detrend(df["interpolated_signal"])

# 4. **Outlier Removal** - Using Interquartile Range (IQR)
Q1 = df["detrended_signal"].quantile(0.25)
Q3 = df["detrended_signal"].quantile(0.75)
IQR = Q3 - Q1
df_clean = df[(df["detrended_signal"] >= Q1 - 1.5 * IQR) & (df["detrended_signal"] <= Q3 + 1.5 * IQR)]

# 5. **String-Based Sensor Failures Handling**
df_clean.replace({"sensor_failure": {"NaN": np.nan, "ERROR": np.nan}}, inplace=True)

# 6. **Resampling to Known Sampling Frequency**
sampling_rate = "1S"  # Assuming sensor data should be recorded every second
df_resampled = df_clean.resample(sampling_rate).mean()

print(df_resampled.head())
