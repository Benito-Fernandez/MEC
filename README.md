This repository has several tools (mostly in Python) that attempt to provide mechanisms to simulate Recurrent Neural Networks to reprsent Nonlinear Dynamic Systems.

These include:
 - NARMAX (Nonlinear Auto-Regressive Moving-Average)
 - DyNet (Dynamic Network)
 - pyNNet (Pythongeneric Neural Network)
 - testActivation&Loss.  Various Activation Functions and Loss/Cost Function for NNets.
 - UniversalNeuralNetworks
